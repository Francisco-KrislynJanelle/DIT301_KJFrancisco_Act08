# Screenshots

This directory should contain the following screenshots of the running app:

## Required Screenshots

1. **permission_request.png**
   - Shows the permission request dialog or screen
   - Demonstrates how the app asks for location permissions
   - Should show the explanation text and grant button

2. **map_location.png**
   - Shows the Google Map with the user's location marker
   - Demonstrates the main functionality of the app
   - Should show the map, marker, and any UI elements

3. **location_update.png**
   - Shows the location coordinates being displayed
   - Demonstrates real-time location updates
   - Should show the coordinate information card at the bottom

## How to Take Screenshots

1. Run the app on a physical device or emulator
2. Grant location permissions when prompted (screenshot #1)
3. Wait for the map to load and show your location (screenshot #2)
4. Show the location coordinates at the bottom (screenshot #3)
5. Save screenshots as PNG files with the exact names above

## Screenshot Guidelines

- Use high-resolution screenshots (1080p or higher)
- Ensure UI elements are clearly visible
- Show the app in portrait orientation
- Include the status bar and navigation bar if present
- Make sure location marker and coordinates are visible
